- Component Folder: [`src/app/su-user-links`](../../app/su-user-links)
- Component Selector: `su-user-links`

## Description

This add-on adds configurable custom links to the NDE user area menu. 

## Configuration

The component reads link values from `MODULE_PARAMETERS` using numbered keys:

- `href1`, `text1`, `ariaLabel1`
- `href2`, `text2`, `ariaLabel2`
- `href3`, `text3`, `ariaLabel3`

You can continue the same pattern for additional links.
